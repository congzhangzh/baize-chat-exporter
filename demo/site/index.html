Sure. This uses matplotlib only:

python
import matplotlib.pyplot as plt

months = ["Jan", "Feb", "Mar", "Apr", "May", "Jun"]
signups = [1240, 1310, 1505, 1620, 1980, 2310]

fig, ax = plt.subplots(figsize=(8, 4))
ax.bar(months, signups, color="#5eead4")
ax.plot(months, signups, color="#0f766e", marker="o")
for m, n in zip(months, signups):
    ax.annotate(f"{n:,}", (m, n), ha="center", va="bottom")
ax.set_title("Monthly sign-ups")
plt.show()

Swap plt.show() for plt.savefig("signups.png", dpi=150) to write a file instead.
