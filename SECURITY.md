# Security Policy

This extension reads chat conversations — including WhatsApp Web personal
messages — inside the user's own browser, so we take reports seriously.

- Report vulnerabilities privately via
  [GitHub private vulnerability reporting](https://github.com/congzhangzh/baize-chat-exporter/security/advisories/new).
- Do not open public issues for exploitable problems.
- No bounty program; we aim to acknowledge reports within 7 days.
